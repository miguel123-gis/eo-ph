Easy Satellite

easy-satellite.com/download is an easy way to download Sentinel-2 images in the Philippines.

Parameters

Latitude - in WGS84 e.g. 8.465630088400024
Longitude - in WGS84 e.g. 124.64176985865824
Start date - in YYYY-MM-DD e.g. 2024-01-01
End date - in YYYY-MM-DD e.g. 2024-03-30
Buffer - distance in meters that will buffer the point and serve as the clip box
Frequency - either monthly, quarterly, or yearly
Mode - either regular, annotate, export_all or cloudless

Modes

Regular - Given a date range, get the image per month, quarter, etc. with the least cloud cover.

Disclaimer: The cloud cover is calculated per Sentinel-2 tile. So, in this tile, some areas may still have clouds.

Annotate - Same as regular but will add information. Output images are not georeferenced.

Export all - Same as regular but will export the individual bands and the true color composite.

Cloudless - Given a date range, get the latest image and replace its cloud pixels with the next most recent image and so on. Output is a single image only.
